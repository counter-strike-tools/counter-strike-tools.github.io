Frequently asked questions

Start here before wiring your project.

Which repo should I use first?

Use `cs2-dumper` to generate output. Use `cs2-dumper-sdk` when an application needs to consume that output.

What output format should downstream tools target?

Target the JSON layout under `output/json` and `output/metadata`. Flat-layout compatibility is supported for older consumers.

Does the SDK require generated files?

No. The SDK can load an output directory or run the dumper and consume stdout JSON directly.

Where are releases published?

Release artifacts are published from the `cs2-dumper` repository on GitHub.
